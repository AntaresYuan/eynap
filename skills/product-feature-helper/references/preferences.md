# 用户偏好沉淀

跨会话复用用户的稳定偏好，避免每次重复问同样的问题。

## 文件位置

```
<主项目目录>/.product-feature-helper-prefs.md
```

放在用户的项目目录而非 skill 目录内：skill 可能被更新覆盖，且偏好属于用户资产。

## 使用时机

**流程开始时**：先检查该文件是否存在。
- 存在 → 读取并应用，跳过已记录的提问，只确认关键项
- 不存在 → 走完整问答，结束后创建

**流程结束时**：把本次确认的稳定偏好写入或更新。

## 该记什么

只记**跨任务复用**的稳定偏好：

- 常改的站点及其技术栈、危险区（省掉重复侦察）
- 执行方式偏好（浏览器直接改 / Console 脚本）
- 视觉风格倾向（配色、圆角、阴影浓淡、组件位置习惯）
- 站点专属的稳定选择器（原生按钮、输入框等复用锚点）
- 明确表达过的做法禁忌

## 不该记什么

- 一次性的具体改动内容
- 临时的调整参数
- 未经确认的推测

## 文件模板

```markdown
# product-feature-helper 用户偏好

## 执行方式
- 默认偏好：Console 脚本（用户习惯自己粘贴、便于反复调整）
- 例外：改动涉及多轮视觉微调时，接受浏览器直接改

## 视觉风格
- 主色：#3370FF
- 圆角：10px（面板）/ 50% （悬浮球）
- 阴影：偏柔和，两层叠加
- 悬浮组件默认位置：右下角，可拖拽

## 常改站点

### app.example.com/workspace
- 技术栈：React + CSS Modules（类名带哈希，构建后会变，勿写死）
- 危险区：
  - 输入框是 Slate 编辑器 → 禁止代码写入，只能剪贴板 + focus
  - 对话消息列表疑似虚拟化 → 禁止插入节点
- 可复用的原生锚点：
  - 「发起人工支持」原生按钮：复用其 click() 最稳
- 历史注入：悬浮球 + FAQ 手风琴 + 人工支持入口

## 做法禁忌
- 不要尝试自动填入/自动发送到富文本输入框（已实测崩溃两次，用户明确接受手动粘贴方案）
```

## 更新原则

- 用户表达的新偏好与已记录的冲突 → **替换旧的**，不要并列保留矛盾条目
- 新发现的站点危险区 → 追加到对应站点条目下
- 用户明确否决过的做法 → 记进"做法禁忌"，避免重复踩

## 与全局偏好的边界

本文件只存 product-feature-helper 相关的偏好。用户表达的**跨领域通用偏好**（如回复语言、沟通风格）写进全套共用的偏好文件 → [../_shared/preferences.md](../_shared/preferences.md)，不写在这里。本文件只放站点级、做法级的 PFH 专属偏好。
